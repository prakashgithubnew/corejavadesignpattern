**Below are some Behavioral Design Pattern Used in core java**
--------------------------------------------------------------
These design Pattern focus on the interactions and communication between objects.

**Observer Design Pattern**
---------------------------

    Defines a one-to-many dependency, so when one object changes state, its dependents are notified.
    Use Case: Event handling in GUI frameworks.

**Strategy Design Pattern**
---------------------------    
    Encapsulates multiple algorithms and selects one at runtime.
    Use Case: Sorting algorithms, payment methods.
