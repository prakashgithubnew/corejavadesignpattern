**Below are some structural Design Pattern Used in core java**
--------------------------------------------------------------

**Adapter Pattern**
-------------------
    Converts one interface into another, making incompatible interfaces work together.
    Use Case: Connecting legacy code with new systems.

**Decorator Pattern**
---------------------

    Adds new functionalities dynamically to objects without modifying their structure.
    Use Case: Adding features like encryption, logging, or caching.

**Proxy Pattern**
------------------

    The Proxy Pattern is a structural design pattern that provides a surrogate 
    or placeholder for another object to control access to it.
